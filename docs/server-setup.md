# Подготовка развёртывания образа

Приложение публикуется в `ghcr.io/nkt2006/devops-ci-app`.
Пакет публичный: чтение не требует персонального токена.

## Выбор версии

Для развёртывания выбирается полный SHA коммита последнего успешного запуска
CI по событию `push` в `main`. SHA берётся из заголовка запуска и списка тегов GHCR.
Перед применением нужно записать выбранный SHA и digest в переменные inventory
или release manifest. `latest` применяется только для ознакомительной проверки,
поскольку после новой публикации этот указатель изменяется.

Проверка опубликованного артефакта: `docker pull ghcr.io/nkt2006/devops-ci-app:<SHA>`.
Вместо тега можно закрепить содержимое по `@sha256:<digest>`.

## Параметры целевого узла

- учебный SSH-узел: `devops`, пользователь `devops`;
- платформа образа и VM: `linux/arm64`;
- Docker Engine уже установлен;
- процесс приложения: пользователь `app`, UID 999;
- внутренний HTTP-порт: `5000`;
- проверка готовности: `GET /health`, HTTP 200 и JSON `{"status":"ok"}`;
- тестовый порт узла: только `127.0.0.1:5001`, для запуска по SHA — `127.0.0.1:5002`;
- приложения предыдущих практик используют другие контейнеры и сохраняются.

Пароли, закрытые SSH-ключи и токены не сохраняются в репозитории.
При будущем Ansible-развёртывании образ загружается из GHCR без пересборки на VM.
После запуска проверяются health-ответ, пользователь контейнера и журнал Gunicorn.
